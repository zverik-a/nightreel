# Changelog

## 0.1.0 — unreleased

First release.

- Interactive fzf UI: search, featured, trending, top rated, newest, categories, favorites,
  history, with a live preview pane and optional thumbnails (chafa).
- Streaming in mpv with quality cap and resume; other players supported via resolved URLs.
- Downloads via yt-dlp with progress, quality presets, batch files and multi-select.
- Local favorites and history (SQLite), incognito mode, panic key.
- Scriptable commands with `--json`, `doctor`, config file + env overrides, proxy support.
- Provider plugin interface; default provider uses the site's JSON API.
